# 🪞 Fitton Booth

Fitton Booth is a full-stack Augmented Reality (AR) application designed for retail dress shops. It modernizes the in-store shopping experience by allowing customers to virtually "try on" dresses through a live camera feed. Using advanced body tracking and 3D cloth physics, the application dynamically overlays digital garments onto the user in real-time, handling occlusion and scale automatically.

## ✨ Key Features
* **Real-Time AR Try-On:** Seamlessly tracks human landmarks to anchor and scale 3D clothing meshes over a live video feed.
* **Cloth Simulation:** Integrates dynamic physics so virtual fabrics stretch, drape, and move naturally with the user.
* **Interactive Catalog:** A responsive frontend UI where users can browse dress inventory and instantly apply different AR lenses.
* **Shop Owner Dashboard:** A secure backend system for shop owners to manage inventory, update pricing, and catalog digital assets.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **AR Engine:** Snap Camera Kit Web SDK (Lens Studio)
* **Backend:** Python / Node.js
* **Database:** PostgreSQL
* **Asset Generation:** AI-powered 2D-to-3D mesh generation (e.g., Meshy API)
